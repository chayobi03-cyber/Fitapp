# Samsung Health Data SDK local dependency

Download Samsung Health Data SDK v1.1.0 from Samsung Developer and place the supplied `samsung-health-data-api.aar` here.

Do not commit the proprietary SDK binary to this repository.

The SDK requires:
- Android 10 / API 29+
- Java 17+
- Samsung Health 6.30.2+
- Physical Android device; emulator unsupported

For development/testing, enable Samsung Health > Settings > About Samsung Health > Developer Mode (Samsung Health Data SDK) > Data Read.
