# Git Bootstrap Note

The repository was empty at project start. Initial governance files were therefore initialized on `main` because GitHub cannot create a branch from an empty repository without an existing ref.

Initial history is intentionally limited to project governance/bootstrap documents.

Going forward:
- create a feature branch from the current `main` HEAD before changes
- stage only confirmed paths
- review diff/status before commit
- push only with explicit authorization
- never force-push or rewrite history
